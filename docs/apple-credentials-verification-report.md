# Apple Credentials — Safe Verification Note

تمت مراجعة مسارات Apple للتأكد من أن قيم الاعتماد تُقرأ من متغيرات البيئة
والأسرار المدارة فقط. لا تُحفظ ملفات `.p8` أو محتويات PEM أو رموز الاعتماد في
المستودع.

## القاعدة التشغيلية

- تُدار مفاتيح Apple من Replit Secrets أو مدير أسرار Codemagic.
- أي مفتاح ظهر في Git أو سجل بناء يُعتبر مكشوفاً ويجب إلغاؤه وتوليد بديل.
- لا تُحفظ قيم Key ID أو Issuer ID أو private key في لقطات الشاشة أو التوثيق.
- فحص الأسرار المحلي `npm run security:check` جزء من التحقق قبل النشر.

هذا المستند لا يحتوي على أي قيمة اعتماد أو مادة مفتاح خاصة.
