# إدارة الموقع والاشتراك

## لوحة الإدارة

من صفحة إدارة الطلبات، افتح المشروع ثم تبويب **الإدارة السريعة**. يتيح للمشرف أو المدير:

- إيقاف الموقع أو إعادة تشغيله يدويًا.
- تفعيل الإيقاف التلقائي عند انتهاء الاشتراك.
- تخصيص رسالة الإيقاف (حتى 1000 حرف).
- مراجعة حالة الاشتراك ورابط الموقع.

## واجهات API

تتطلب الواجهات الإدارية جلسة دخول بدور `admin` أو `manager`.

### قراءة الإعدادات

`GET /api/admin/projects/:projectId/quick-management`

يعيد حالة التحكم ورسالة الإيقاف وتاريخ نهاية الاشتراك، دون أي أسرار أو بيانات عملاء.

### تحديث الإعدادات

`PATCH /api/admin/projects/:projectId/quick-management`

```json
{
  "manualSuspended": true,
  "autoSuspendOnExpiry": true,
  "suspensionMessage": "الموقع متوقف مؤقتًا. تواصل مع QIROX للمساعدة."
}
```

الحقول اختيارية، ورسالة الإيقاف مطلوبة إذا أُرسلت. أقصى طول لها 1000 محرف.

### حالة عامة للموقع المُنشأ

`GET /api/public/projects/:projectId/site-status`

واجهة عامة بلا مصادقة؛ ترجع فقط `suspended` و`message` و`contactUrl`. لا ترجع بيانات المشروع أو العميل أو الاشتراك المالية. تستخدم قوالب SaaS المُنشأة هذه الواجهة لعرض شاشة الإيقاف ورفض طلبات API عند التعليق.

عند تعذر الاتصال بمنصة QIROX، يحافظ خادم الموقع المُنشأ على توفره مؤقتًا بدل إيقاف موقع سليم بسبب انقطاع لوحة التحكم. يعاد فحص الحالة كل 30 ثانية.

## واجهة بيانات النظام المُنشأ

واجهات قراءة كتالوج المنتجات والطلبات والعملاء والمخزون تخص قاعدة بيانات كل نظام مُنشأ، وليست بيانات قاعدة QIROX المركزية. يستخدم النظام المُنشأ واجهات `/api/v1` ومفاتيح نطاقات القراءة الخاصة به؛ اكتشاف المسارات متاح على `GET /api/v1`. لا تستخدم مفتاح تكامل المشروع لإرسال البريد أو واتساب على أنه مفتاح قراءة لبيانات النظام.

القوالب الجديدة والمحدّثة تضيف:

- `GET /api/v1/invoices` بنطاق `invoices:read`، مع ترقيم صفحات وفلاتر تاريخ وحالة.
- `GET /api/v1/subscription` بنطاق `subscription:read` لقراءة باقة النظام.
- `GET /api/v1/projects/:projectId/subscription` بنطاق مفتاح تكامل QIROX من نوع `api` لقراءة اشتراك المشروع وتاريخ انتهائه، بما في ذلك آخر تجديد معتمد.

التوثيق الكامل للمفاتيح والنطاقات والحقول في كل نظام مُنشأ: `docs/EXTERNAL-API.md`.
