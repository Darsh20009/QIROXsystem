# Sprint A — ملخص أمني منقح

تمت معالجة مسارات الأمان المتعلقة بالجلسات، تشغيل sandbox، رفع الملفات،
WebSocket، رؤوس HTTP، وتسجيل الطلبات.

## قواعد الحماية

- الأسرار تُقرأ من مدير الأسرار فقط.
- أوامر sandbox تمر عبر قائمة سماح ولا تُشغّل مدخلات غير موثوقة مباشرة.
- اتصالات WebSocket تعتمد على هوية الخادم، لا على `userId` يرسله العميل.
- مسارات ملفات الإعداد والمفاتيح تُغلق باستجابة عامة ولا تكشف وجودها.
- سجلات الخادم لا تحتوي على أجسام الاستجابات أو قيم الاعتماد.

## التحقق

استخدم `npm run security:check` قبل كل نشر. إذا ظهر تسريب في Git، يجب تدوير
السر أولاً ثم تنظيف التاريخ المتأثر، وليس الاكتفاء بحذف الملف من آخر commit.

هذا الملخص منقح ولا يحتوي على مفاتيح أو رموز أو بيانات اعتماد.
