---
name: Executive identity SEO
description: How to correct public leadership identities without losing already-indexed image URLs.
---

When a public executive profile image is corrected, keep its established canonical URL and replace the file contents rather than introducing only a new image path.

**Why:** Search engines and third-party previews can retain old image URLs long after page metadata changes. Preserving the URL lets their next fetch receive the corrected portrait and avoids leaving an indexed broken or mismatched asset behind.

**How to apply:** Update the matching profile page metadata, structured data, public information feed, and sitemap caption at the same time; inspect the rendered crop to ensure the image itself contains no obsolete role or name label.
