---
name: Public team profile policy
description: Guardrails for representing employees on QIROX public pages.
---

Only show named employee profiles when both the identity and portrait are verified for public use. If approved staff assets are unavailable, show verified leadership profiles and describe the wider team collectively; do not query protected employee endpoints for public content or invent identities.

**Why:** The authenticated employee directory can contain private data, and fabricated or unapproved portraits would misrepresent staff.

**How to apply:** Confirm each name and image is approved for the public page before adding profile cards. Otherwise, keep a collective team panel.
