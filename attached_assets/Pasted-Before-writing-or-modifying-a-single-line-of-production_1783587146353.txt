Before writing or modifying a single line of production code, we are establishing permanent engineering standards for the entire project.

You are NOT allowed to make assumptions.

You are NOT allowed to make design decisions.

You are NOT allowed to invent UI.

You are NOT allowed to choose colors.

You are NOT allowed to choose typography.

You are NOT allowed to create layouts.

You are ONLY an implementation engineer.

--------------------------------------------------

STEP 1

Read every document inside /docs.

Treat these documents as the only source of truth.

If conflicts exist between documentation and implementation, documentation wins.

--------------------------------------------------

STEP 2

Create a new folder:

/standards

Inside it create the following files:

CODE_STANDARDS.md

REACT_STANDARDS.md

NODE_STANDARDS.md

API_STANDARDS.md

DATABASE_STANDARDS.md

SECURITY_STANDARDS.md

PERFORMANCE_STANDARDS.md

TESTING_STANDARDS.md

MOBILE_STANDARDS.md

SEO_STANDARDS.md

ACCESSIBILITY_STANDARDS.md

DEPLOYMENT_STANDARDS.md

ERROR_HANDLING.md

LOGGING.md

MONITORING.md

--------------------------------------------------

STEP 3

Every standard must define:

Purpose

Rules

Allowed

Forbidden

Examples

Checklist

Common mistakes

Future scalability considerations

--------------------------------------------------

STEP 4

Create an implementation order.

Nothing may be implemented randomly.

Break the entire rebuild into Sprints.

Every Sprint must contain:

Objective

Files affected

Dependencies

Testing requirements

Rollback strategy

Estimated complexity

--------------------------------------------------

STEP 5

Generate a dependency graph.

Show which modules depend on other modules.

Identify circular dependencies.

Identify modules that must be separated.

--------------------------------------------------

STEP 6

Generate a technical debt report.

Group technical debt into:

Critical

High

Medium

Low

Estimate the effort to remove each item.

--------------------------------------------------

IMPORTANT

Do NOT modify production code.

Do NOT redesign UI.

Do NOT fix bugs.

Do NOT refactor.

Do NOT install packages.

Do NOT remove packages.

Documentation only.

When everything is complete, stop and wait for approval.
